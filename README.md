A modern, responsive digital background and wallpaper web application featuring curated high-definition 4K desktop and mobile wallpapers with dynamic themes and device previews.

---

## 🌟 Key Features

- **📱 Desktop & Mobile Switcher**: Toggle easily between Landscape (desktop) and Portrait (mobile) views.
- **🎨 Custom Aesthetic Themes**: Adjust accent colors, glassmorphism blur, and contrast.
- **🔍 Categorized Galleries**: Minimalist, Space & Cosmic, Cyberpunk, Nature, Abstract, and Architecture.
- **💻 Live Screen Mockup Previews**: Test wallpapers on phone and monitor frames.
- **❤️ Favorites Storage**: Save and access favorites offline via localStorage.

---

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/akkibawane/digital-background.git

# Navigate into the project folder
cd digital-background

# Install dependencies
npm install

# Run development server
npm run dev
```

---

## 📦 Production Build

```bash
# Build production bundle
npm run build

# Preview build locally
npm run preview
```

---

## 🚢 Deployment

Automated deployment is configured via GitHub Actions in [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml). Any push to `main` automatically triggers Vite build and publishes to GitHub Pages.
